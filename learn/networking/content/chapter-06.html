CHAPTER 06 · GUIDED LESSONS

Link Layer and LANs

How neighboring devices deliver frames over a link. Open any module for a five-page lesson with an explanation, a worked example, guided practice, and a checkpoint.

6.1 · MODULE

Link services and error detection

Link protocols frame datagrams and detect corruption with tools such as checksums, parity, and CRC.

The link layer moves a datagram across one link between adjacent nodes. Its services may include framing, medium access, reliable delivery, and error detection; the exact set depends on the link technology.

In practice: Ethernet and Wi-Fi both carry IP datagrams, but their framing and access rules differ.

6.2 · MODULE

Error detection and correction

Parity, checksums, and cyclic redundancy checks detect corrupted frames; recovery requires retransmission or additional redundancy.

Parity, checksums, and cyclic redundancy checks let a receiver detect corrupted frames. CRCs detect many common burst errors, but detecting corruption does not always let a receiver repair the data.

In practice: An Ethernet CRC can expose corruption so the frame is discarded and a higher layer may retransmit.

6.3 · MODULE

Multiple-access protocols

Channel partitioning, random access, and taking-turns protocols coordinate devices that share a broadcast medium.

Multiple-access protocols coordinate devices sharing a broadcast medium. Channel partitioning reserves frequencies or turns; random access allows contention; taking-turns protocols grant transmission opportunities in sequence.

In practice: Wi-Fi uses contention to share airtime, while cable networks coordinate upstream transmissions.

6.4 · MODULE

ARP and Ethernet switching

ARP resolves a local IPv4 next hop to a MAC address; Ethernet switches learn source addresses and forward frames across a LAN.

A link-layer address identifies an interface on a local link. ARP resolves an IPv4 address to a MAC address; Ethernet switches learn source addresses and forward frames toward the right port.

In practice: For an off-subnet destination, a laptop sends the frame to its router’s MAC address, not the remote server’s.

6.5 · MODULE

VLANs, MPLS, and data centers

VLANs segment switched LANs, MPLS steers provider traffic with labels, and data-center fabrics connect large server populations.

VLANs create logical LAN segments across physical switches; MPLS uses labels to steer packets through provider networks. Data centers use fabrics with many paths to connect servers at scale.

In practice: A VLAN can isolate guest devices; a data-center fabric provides parallel paths between racks.
