CHAPTER 01 · LESSON

The Internet under the hood

Start with the whole path: applications create data, networks carry packets, and protocols coordinate each step.

1.1–1.3 · STRUCTURE

Edge, access, core

Applications run on end systems at the network edge. Access networks connect them to routers; the network core forwards packets between networks.

1.3–1.4 · PERFORMANCE

Packets have a cost

Packet switching shares links. Each hop can add transmission, propagation, processing, and queueing delay; congestion can cause loss.

1.5 · ORGANIZATION

Layers and encapsulation

Each layer provides a service to the one above. As data moves down the stack, each layer adds control information; the receiver removes it on the way up.

Key distinction: Transmission delay is the time to place packet bits onto a link. Propagation delay is the time those bits travel across the link.
