What does the application say?

Protocols such as HTTP define the request and response that your software understands. DNS and SMTP also live in this application layer model, even though they serve different jobs.

TRACE POSITIONReady · Layer 7 Application

Start at the application layer. Select any layer above to inspect its job.

How to use the model: OSI is a teaching and troubleshooting map, not a promise that every Internet protocol fits one box. The Internet stack commonly groups OSI layers 5–7 as application, layer 4 as transport, layer 3 as Internet, and layers 1–2 as link. TLS, QUIC, and session behavior can cross these boundaries.
