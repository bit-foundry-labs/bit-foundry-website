FIELD NOTES / NETWORKS

Internet field notes

Small details behind the network that makes the Web possible. Open a note to reveal the fact.

01 / TWO IDEASThe Internet and the Web are different

The Internet is the global network infrastructure. The World Wide Web is one service built on top of it, using linked pages and browsers. Email and online games also use the Internet without being the Web.

02 / A SHARED LANGUAGEARPANET switched to TCP/IP on one day

On 1 January 1983, ARPANET made the transition to TCP/IP. A shared protocol let different networks interconnect and helped shape the modern Internet.

03 / CERN, 1989The Web began as a way to share research

Tim Berners-Lee proposed the Web at CERN to help researchers share information across institutions. It started as a practical collaboration tool.

04 / FIRST SERVERThe first website ran on a NeXT computer

By the end of 1990, CERN had the first Web server and browser running. The server lived on the NeXT computer in Berners-Lee's office.

05 / OPEN WEBCERN released the Web software in 1993

On 30 April 1993, CERN put the World Wide Web software in the public domain, helping others build on it freely.

06 / BUILDING BLOCKSURLs, HTTP and HTML solve different problems

A URL names where a resource can be found, HTTP defines how a browser and server exchange it, and HTML describes the page structure. Together they made a simple, reusable publishing system.
