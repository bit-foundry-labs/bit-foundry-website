# ¡Ándale! · Español de México

A mobile-first Mexican Spanish language app with **one shared web codebase** for a public website, installable PWA, and an iPhone/iPad application via Capacitor.

## Live web app
https://andale-espanol-mx.onrender.com

Render deploys the `andale/` folder of the `andale-app-preview` branch as a static site. The page and lesson engine stay in `index.html` for now; later we can split into components without rewriting exercises.

## Run on desktop or mobile browser
From this folder:

```bash
python3 -m http.server 8080
```

Visit http://localhost:8080. On a phone, visit the public HTTPS URL. Lesson progress is saved locally in each browser with localStorage. **It does not sync between devices yet.**

## Install the web app
On iPhone/iPad, open the HTTPS address in Safari, use Share > Add to Home Screen, then Open as Web App if offered. Chrome can use the same HTTPS web app normally. On supported Chrome platforms, use the Install option if offered. The service worker caches the lesson interface for subsequent offline use; the first visit must be online.

## iPhone/iPad native project

Prerequisites: Node.js 22+, npm, and for building/signing iOS, **macOS with Xcode 26+** (or a cloud macOS build environment).

```bash
cd andale
npm install
npm run ios:init
npm run ios:open
```

Run `ios:init` only the first time. On subsequent changes, run `npm run ios:sync` to copy the latest web files into the native project. `ios:open` opens Xcode on macOS.

The iOS app bundles its lesson files inside the app, rather than merely pointing its WebView to the live website. iOS projects are generated by Capacitor and must be built, signed, and tested with Xcode. The bundle identifier is `io.bitfoundrylabs.andale` and should be reviewed before App Store enrollment.

## Release path
1. Complete iPhone/iPad UI testing: safe-area sizing, keyboard, audio pronunciation, progress persistence and offline behavior.
2. Generate native project and verify an unsigned simulator build on a macOS runner or Mac.
3. Join Apple Developer Program, set team/signing and a branded native icon, distribute through TestFlight.
4. Submit to App Review after adding accessibility, user support, privacy disclosures and any required native features.

Apple's Developer Program currently charges $99/year, or a local-currency equivalent.

## Structure

```text
andale/
  index.html                 public web app and lesson engine
  manifest.webmanifest       installable web app metadata
  service-worker.js          offline app-shell caching
  assets/andale-mark.svg     branded icon
  package.json               Capacitor and native build scripts
  capacitor.config.json      iOS app ID / shared web asset directory
  scripts/build-native.mjs   assemble the native offline bundle
  www/                       generated by build-native; do not edit
  ios/                       generated by Capacitor on init
```

The separate public Bit Foundry website remains untouched.
