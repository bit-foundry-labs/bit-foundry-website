# Maison Fleur | Handshake AI Skills Studio

**Mission:** Create Your Inbox Assistant (OpenAI)

Maison Fleur is a French botanical correspondence interface paired with a private ChatGPT Gmail assistant. The assistant reviews full email threads, identifies genuinely unanswered conversations, prioritizes personal and time-sensitive messages, prepares response drafts for human approval, and performs a recurring inbox check. It never sends messages automatically.

## How the submission satisfies the mission

- **Connect a real inbox:** The owner connects Gmail to ChatGPT; this public interface does not access or expose Gmail.
- **Review AI replies:** ChatGPT proposes/contextualizes messages and prepares Gmail drafts. The owner must review or edit before sending.
- **Recurring assistant:** A scheduled ChatGPT task performs the daily inbox check at 09:00 America/Mexico_City.
- **Human-in-the-loop:** No automatic Send actions. Existing drafts are preserved.
- **Interface:** The public Maison Fleur website is a visual, interactive demonstration with fictional sample correspondence.

## Privacy boundary

The public demonstration contains **no real email, private messages, or Google access tokens**. The existing connected Gmail and scheduled assistant live inside the owner's private ChatGPT account. A future standalone website Gmail integration would require a separate OAuth setup and a secure server; the demonstration does not claim that integration exists.

## Technical showcase

A standalone HTML/CSS/JavaScript interface features four custom French-country stationery collections, paper-and-ink choices, letter reading, reply editing, and local draft previews. The app uses original generated envelope illustrations.
